# Azyet Fine Cuts

Aprofessional web presence for **Azyet Fine Cut**

## Project overview

This is a multi-page static website designed to showcase shop services, sharing grooming expertise via blog and facilitate customer grooming.

## Getting started

1. Clone this repository on your local machine.

```bash
git clone http:github.com/..Azyet_fine_cuts

cd azyet_fine_cuts
```
2. open `index.html` in any modern browser to view the site.

3. No build tools or dependencies required for this static version.

## Tech Stack
- **HTML5**: Semantic structure for accessibility and SEO.
- **Markdown**: For project documentation.

## How to collaborate
We welcome contributions! To maintin code quality and project integrity, please follow these steps

### The workfow
- **Fork the repository:** Create your own copy to work on.
- **Create a feature branch:**
```bash
git checkout -b feature/
YourFeatureName
```

- **commit your changes:** Use decriptive commit messages (eg. , feat: add social media icons to the footer).
- **Push to branch:**
```bash
git push origin feature/
YourFeatureName
```

- **Open a pull Request (PR):**
Describe your changes clearly and link the related issues.
